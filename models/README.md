# ⚙️ Modelos 3D

[⬅️ Volver al README principal](../README.md)

Archivos STL de las piezas impresas del vehículo. Todas se diseñaron en **Onshape** y se imprimieron en **PETG**; las piezas de la dirección van en **PETG-CF**. Los parámetros de impresión están en la sección *10.7 Manufactura aditiva* del README principal.

---

## 🚗 Piezas del vehículo 2026

| Archivo | Pieza | Dónde va |
| :--- | :--- | :--- |
| [`Primer_Piso_Vehiculo_2026.stl`](Primer_Piso_Vehiculo_2026.stl) | Monochasis (primer piso) | Base del vehículo: cama del motor, rodamientos, soportes de los ToF y compartimento de la batería |
| [`Segundo_piso_vehiculo_2026.stl`](Segundo_piso_vehiculo_2026.stl) | Segundo piso | Electrónica y base de las torres Shark Fin |
| [`Separador_2026.stl`](Separador_2026.stl) | Separador de 60 mm | Entre los dos pisos, con insertos de latón M3 en los extremos |
| [`Engranaje_15teeth_2026.stl`](Engranaje_15teeth_2026.stl) | Piñón de 15 dientes | Eje del motor (agujero en "D", a presión) |
| [`Engranaje_25teeth_2026.stl`](Engranaje_25teeth_2026.stl) | Corona de 25 dientes | Eje trasero, con abrazadera tipo "C" |
| [`Adaptador_Lego_2026.stl`](Adaptador_Lego_2026.stl) | Adaptador de rueda Lego | Extremos del eje trasero |
| [`Torre_Izquierda_2026.stl`](Torre_Izquierda_2026.stl) | Torre Shark Fin izquierda | Segundo piso, 3 insertos M3 en la base |
| [`Torre_Derecha_2026.stl`](Torre_Derecha_2026.stl) | Torre Shark Fin derecha | Segundo piso, 3 insertos M3 en la base |
| [`Base_Fija_Mordaza_2026.stl`](Base_Fija_Mordaza_2026.stl) | Mordaza fija | Entre las torres; pivota para ajustar el ángulo de la cámara |
| [`Mordaza_Movil_2026.stl`](Mordaza_Movil_2026.stl) | Mordaza móvil | Dentro de la mordaza fija; sujeta el teléfono |
| [`Tornillo_Mordaza_2026.stl`](Tornillo_Mordaza_2026.stl) | Tornillo M10 impreso | Rosca M10.5 de la mordaza fija; empuja la mordaza móvil |

> [!NOTE]
> Las piezas de la **dirección Ackermann** (manguetas, barra de acoplamiento, biela y soporte del servo) se agregarán a esta carpeta. Sus medidas están en [`docs/direccion-ackermann.md`](../docs/direccion-ackermann.md).
